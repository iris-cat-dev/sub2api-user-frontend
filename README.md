# sub2api-user-frontend

## API 密钥导入 CC-Switch

密钥页面点击「导入到 CCS」后，先选择导入平台：Anthropic → Claude、OpenAI → Codex、Gemini → Gemini、Grok → Grok Build。选择 Antigravity 时，再选择 Claude / Gemini 客户端；完成选择后才通过 `ccswitch://v1/import` 唤起本机 CC-Switch，取消或关闭弹窗不会触发导入。

导入目标以弹窗选择为准，不由密钥分组自动决定，也不会修改密钥绑定的分组。服务地址沿用 `https://codex.mintcat.work`；Grok 使用 `/v1` 端点，Antigravity 使用 `/antigravity` 端点。实际调用仍需密钥所属分组支持对应协议；本机需已安装 CC-Switch 并注册协议处理程序。

## AI 对话

登录后从侧栏「AI 对话」进入 `/chat`，复用主站布局、登录态以及现有亮色/暗色主题。API 密钥、模型和协议位于输入框底部的紧凑工具栏；搜索、刷新、手动模型 ID 及发现错误收在对应选择器内。选择当前账号下已启用、绑定有效分组的 API 密钥后，通过同源 `/v1/models` 获取可用聊天模型；已保存但不可用的密钥会明确提示，不会自动换用其他密钥。

支持多轮上下文、流式回复、Markdown 代码块与表格、推理过程展开、复制消息、停止生成和重新生成最后一条回复。消息区采用紧凑布局：用户消息为右侧圆角气泡，时间与操作位于气泡下方，助手回复直接展示在正文区域。可选择 OpenAI Responses（`/v1/responses`）、Chat Completions（`/v1/chat/completions`）或 Anthropic Messages（`/v1/messages`），默认协议按密钥分组平台设置。聊天与模型请求使用所选 API 密钥，不使用主站登录令牌。

输入框支持通过文件按钮、拖放或粘贴添加 PNG、JPEG、WebP、PDF 和文本/代码文件，并可在发送前预览或移除。每条消息最多 5 个文件；图片/PDF 每个最多 8 MB，文本文件每个最多 256 KB，单个对话累计附件最多 20 MB。文本文件作为带文件名的文本上下文发送；图片和 PDF 使用所选协议的原生内容块。附件会随消息保留，后续对话和重新生成继续携带对应上下文。

会话列表支持新建、切换、搜索标题、消息及附件名称、单行紧凑展示、重命名和确认删除；桌面端显示侧栏，手机端使用抽屉。消息、附件、草稿、草稿附件、密钥 ID、模型和协议保存于独立的 `sub2api-chat` IndexedDB，按登录账号隔离，刷新后恢复，不跨浏览器或设备同步；会话记录不保存 API 密钥内容或登录令牌。切换账号或删除运行中的会话会中止相关请求；存储失败会显示错误，重新加载记录时优先保存尚未落盘的回复和草稿。

运行主站 `pnpm dev` 即可使用聊天页面。部署时复用下文的同源 `/api`、`/v1` 转发配置，无需单独的聊天服务。

## 画图工作台

登录后从侧栏进入 `/drawing`，工作台嵌入主站布局。已绑定、启用生图的 OpenAI 与 Grok 分组密钥可选择对应图片模型，普通密钥也会列出并说明不可用原因。支持文生图及 PNG/JPEG/WebP 参考图编辑：OpenAI `gpt-image-*` 最多 16 张参考图，编辑保留原始文件并重复使用 `image` 表单字段上传多图（部分上游拒绝 `image[]`）；文生图默认流式预览，编辑默认非流式（部分上游流式编辑会在 Cloudflare 125 秒限制处超时），两种模式可分别切换预览并支持取消；Grok `grok-imagine-image*` 最多 3 张参考图，编辑通过 JSON 图片数据发送，不提供流式预览。请求均经本站 `/v1/images/generations` 或 `/v1/images/edits` 发出。

开发时可分别运行 `pnpm dev` 与 `pnpm dev:drawing`；独立构建入口位于 `/drawing-app/`，主站内嵌工作台位于 `/drawing`。`pnpm build` 会将主站和独立画图入口一起构建至 `dist/`。Cloudflare Pages 部署 `dist/`，并为预览、生产环境分别配置 `API_UPSTREAM` 指向后端；Pages Functions 将同源 `/api`、`/v1` 请求转发至该地址。

画图任务与图片存于当前站点来源的浏览器 IndexedDB，按登录用户隔离；换设备或浏览器不会同步。与原画图站点共用同一来源时可手动认领其未归属历史；不同来源的浏览器存储不能自动读取。

画廊结果图右上角提供“全屏预览”按钮，点击图片也可打开页面级大图弹层，按原始比例完整显示。历史参考图及已上传参考图支持点击预览；通过关闭按钮、Esc 或点击遮罩关闭，关闭后恢复页面滚动与触发按钮焦点。切换账户时自动清空当前预览。
